AccessLens Setup And Test Checklist

1. Install frontend dependencies

Open the project folder:
C:\Projects\Acceslense\AccessLens

Run:
npm install

2. Set up the database

Create a PostgreSQL database for AccessLens.

Run this SQL file first:
database/schema.sql

Then run this seed/demo data file:
database/seed.sql

The seed file adds a demo template for:
https://www.selenium.dev/selenium/web/web-form.html

3. Configure backend database credentials

Copy:
backend/.env.example

Create:
backend/.env

Fill these values:
DB_HOST=your_host
DB_PORT=5432
DB_NAME=your_database
DB_USER=your_user
DB_PASSWORD=your_password
DB_SSL=false
PORT=4000
AI_PROVIDER=groq
GROQ_API_KEY=your_groq_secret_key
GROQ_BASE_URL=https://api.groq.com/openai/v1
AI_MODEL=openai/gpt-oss-20b

For OpenAI instead of Groq:
AI_PROVIDER=openai
OPENAI_API_KEY=your_openai_secret_key
AI_MODEL=gpt-5-mini

The AI project must also have available credits or free-tier quota. Creating a
secret key does not automatically guarantee successful API calls.

Use DB_SSL=true if your database provider requires SSL.

4. Install backend dependencies

Open:
C:\Projects\Acceslense\AccessLens\backend

Run:
npm install

5. Start the backend API

From the backend folder, run:
npm run dev

Check backend health in the browser:
http://localhost:4000/api/health

Test the template match endpoint:
http://localhost:4000/api/templates/match?url=https%3A%2F%2Fwww.selenium.dev%2Fselenium%2Fweb%2Fweb-form.html

6. Build the extension

From the main project folder, run:
npm run build

This creates the production extension files inside:
dist

7. Load the extension in Chrome

Open Chrome and go to:
chrome://extensions

Turn on Developer Mode.

Click:
Load unpacked

Select the dist folder from this project.

Confirm AccessLens is installed.

8. Test the popup

Click the AccessLens extension icon in Chrome.

The popup UI should open.

9. Test the page overlay

Open this test page:
https://www.selenium.dev/selenium/web/web-form.html

The AccessLens panel should appear on the right side of the page.

To test AI generation, open a supported gov.lk page containing a form for which
there is no approved database template. The first visit can take several seconds.
The panel should display "AI draft" and the generated draft should be stored with
status pending_review. Reloading the same page should reuse that database draft
instead of calling the AI model again.

10. Fill the original form from the overlay

Enter values in the AccessLens panel.

Click:
Fill Original Form

The matching fields in the Selenium test form should be filled.

The form should not submit automatically.

Before approving an AI draft, test every selector and option mapping. Then update
the matching templates row from pending_review to approved.

11. Reload after code changes

After changing frontend or extension files, run:
npm run build

Then go back to:
chrome://extensions

Click the reload button on the AccessLens extension card.

Refresh the Selenium test page if it is already open.

12. Backend and database reminder

The database should store only template/config data.

Do not store:
NIC numbers
names
phone numbers
passwords
OTP codes
filled form values
payment details
